# עוזר פוקר ל-Meta Quest 3S (עובד בלי אינטרנט)

אפליקציה לאימון בטקסס הולדם. המצלמה של ה-Quest מזהה את הקלפים, והאפליקציה מחשבת את הסיכויים שלך.
**הכול רץ על המשקפיים עצמן.** אין מפתח API, אין ענן, ולאפליקציה אין בכלל הרשאת אינטרנט.

## מה היא עושה

### זיהוי אוטומטי (ברירת המחדל)
לא צריך ללחוץ על כלום. המצלמה סורקת כל הזמן, 2–3 פעמים בשנייה, וממלאת את הקלפים לפי סדר היד:
1. **שני הקלפים הראשונים שמסתכלים עליהם מקרוב** הם הקלפים שלך. מבין קלפים חדשים נבחרים הגדולים ביותר, כלומר הקרובים אליך.
2. **קלפים חדשים אחרי זה** נכנסים לשולחן: פלופ, טרן, ריבר.
3. **אחרי הריבר**, שני קלפים חדשים פירושם יד חדשה, והיא מתחילה לבד. אם היד נגמרה מוקדם (כולם ויתרו), לוחצים "יד חדשה".

קלף נחשב רק אחרי שזוהה ב-3 מתוך 4 התמונות האחרונות. קלף שמחקת או החלפת ידנית לא יחזור אוטומטית.

### זיהוי בכפתורים
מכבים את "זיהוי אוטומטי", ואז:
1. **"צלם את הקלפים שלי":** מרימים את שני הקלפים מול העיניים ולוחצים.
2. **"צלם את השולחן":** מסתכלים על הקלפים הפתוחים במרכז ולוחצים.

### החישוב
1. בוחרים **כמה יריבים** עדיין ביד.
2. בוחרים את **סוג היריבים**:
   - **כל יד:** ידיים אקראיות
   - **משחק הרבה:** 50% הידיים החזקות
   - **ממוצע:** 30%
   - **הדוק:** 15%
   - **מהמר חזק:** 7%, למשל מי שנשאר אחרי העלאה גדולה
3. האפליקציה מחשבת מיד:
   - **סיכוי לזכות בקופה** (ניצחון + חלק מקופות מתחלקות)
   - **מה יש לך עכשיו** (זוג, שני זוגות, צבע…)
   - **סיכוי להשתפר עד הריבר** לכל סוג יד
   - אם ממלאים **קופה** ו**סכום ל-Call**: האם ה-Call משתלם לפי Pot Odds

מתחת לתוצאות מוצג הצילום האחרון, עם מסגרת צהובה סביב כל פינת קלף שזוהתה, כדי שתראה מה המודל ראה.
אם הזיהוי טעה, לוחצים על הקלף ובוחרים את הנכון. אפשר גם להזין את כל הקלפים ידנית בלי לצלם.

## איך זה עובד

- **זיהוי הקלפים:** מודל YOLOv8 שאומן על 52 הקלפים רץ על המשקפיים בעזרת ONNX Runtime. המודל מחפש את **הפינות** של הקלפים, שבהן מופיעים המספר והסמל.
  - כל לחיצה מצלמת **3 תמונות ברצף**, וקלף נחשב רק אם הוא זוהה ב-2 מהן לפחות. כך מסוננות טעויות חד-פעמיות.
  - בצילום "הקלפים שלי" נבחרים 2 הקלפים שהמודל הכי בטוח בהם. בצילום "השולחן" נבחרים עד 5, מסודרים משמאל לימין.
- **חישוב הסיכויים:** סימולציית Monte Carlo מחלקת 40,000 פעמים את הקלפים הלא-ידועים ובודקת מי מנצח. הדיוק הוא בערך חצי אחוז.

- **סוגי היריבים:** כל 169 סוגי ידיי הפתיחה מדורגים לפי הסיכוי שלהם מול יד אקראית. הדירוג חושב מראש עם אותו מנוע, 200,000 סימולציות ליד. ליריב "הדוק" נבחרת בכל סימולציה יד רק מתוך החלק החזק של הדירוג, בלי קלפים שכבר גלויים לך.

**חשוב לדעת:** סוג היריב הוא הערכה שלך. הדירוג לא מתחשב בהתנהגות בתוך היד (העלאות בפלופ וכו'), ולכן התוצאה היא קירוב.

**זום למרכז:** אם קלפים רחוקים על השולחן לא מזוהים, מפעילים "זום למרכז". המודל יבדוק רק את מרכז התמונה, ברזולוציה מלאה, ושם הקלפים נראים לו פי 2 גדולים. המלבן הלבן על התמונה מסמן את האזור הנבדק.

**אבחון:** על המסך מוצג זמן הזיהוי לכל תמונה. אם Android Studio מחובר, אפשר לראות כל זיהוי ב-Logcat תחת התג `PokerAssistant`.

### שימוש הוגן
האפליקציה מיועדת לאימון, ללמידה ולמשחקים ביתיים שבהם כל המשתתפים יודעים שאתה משתמש בה. שימוש בעזר כזה במשחק על כסף בלי ידיעת השחקנים האחרים הוא רמאות. בקזינו ובמועדונים זה אסור, ובמקומות רבים גם לא חוקי.

## מה צריך

| | |

| מחשב | Windows או Mac עם [Android Studio](https://developer.android.com/studio) |

| אינטרנט | **רק במחשב, ורק בבנייה הראשונה**, כדי להוריד את מודל זיהוי הקלפים (45MB). המשקפיים לא צריכות אינטרנט |

## התקנה מהירה, בלי Android Studio

אם יש לך קובץ APK מוכן, למשל `poker-assistant-v0.4.apk`:

1. מפעילים **מצב מפתחים** ב-Quest (סעיף 1 למטה).
2. מתקינים במחשב את [Meta Quest Developer Hub](https://developers.meta.com/horizon/documentation/android-apps/meta-quest-developer-hub/) (Windows או Mac).
3. מחברים את ה-Quest בכבל, שמים את המשקפיים ומאשרים **"Allow USB debugging"**.
4. ב-Developer Hub, בעמוד המכשיר, **גוררים את קובץ ה-APK** לאזור האפליקציות. אפשר גם להשתמש ב-SideQuest, או מהטרמינל: `adb install -r poker-assistant-v0.4.apk`.
5. במשקפיים: ספרייה ← **Unknown Sources** ← "עוזר פוקר".

## התקנה מהקוד (פעם אחת)

### 1. הפעלת מצב מפתחים ב-Quest
1. נכנסים ל-[developers.meta.com](https://developers.meta.com/horizon/) עם חשבון ה-Meta שלך ויוצרים "Organization" (בחינם). בלי זה מצב מפתחים לא נפתח.
2. באפליקציית **Meta Horizon** בטלפון: מכשירים ← בוחרים את המשקפיים ← הגדרות משקפיים ← **מצב מפתחים** ← מפעילים.
3. מפעילים מחדש את המשקפיים.

### 2. פתיחת הפרויקט
1. מורידים את הקוד מ-GitHub, מה-branch `claude/modest-lamport-drvsyi`.
2. ב-Android Studio בוחרים **Open** ופותחים את התיקייה `quest-claude-vision`, לא את התיקייה הראשית של ה-repo.
3. מחכים שה-Gradle Sync יסתיים. בפעם הראשונה זה יכול לקחת כמה דקות.

### 3. הרצה על המשקפיים
1. מחברים את ה-Quest למחשב בכבל.
2. שמים את המשקפיים ומאשרים **"Allow USB debugging"**. כדאי לסמן "Always allow from this computer".
3. ב-Android Studio בוחרים את ה-Quest ברשימת המכשירים ולוחצים ▶ **Run**. בבנייה הראשונה המודל יורד אוטומטית.
4. האפליקציה נפתחת במשקפיים. מאשרים את הרשאת המצלמה.

אחר כך אפשר למצוא את האפליקציה בספרייה של ה-Quest, תחת **Unknown Sources**.

## שימוש
1. מפעילים **Passthrough** כדי לראות את החדר (הקשה כפולה על צד המשקפיים, או מההגדרות המהירות).
2. מסתכלים על הקלפים ולוחצים על כפתור הצילום המתאים.
3. בודקים את הקלפים שזוהו, ומתקנים בלחיצה אם צריך.

**טיפים לזיהוי טוב:**
- תאורה טובה, בלי השתקפויות חזקות על הקלפים.
- **הפינות של הקלפים** (המספר והסמל) צריכות להיות גלויות. זה מה שהמודל מחפש.
- לקלפים שלך: מקרבים אותם לפנים, בערך 30–40 ס"מ.
- לשולחן: מסתכלים ישר על הקלפים. אם הם רחוקים, מתקרבים.
- המודל אומן בעיקר על חפיסות סטנדרטיות. בחפיסות מעוצבות הוא יזהה פחות טוב.

## מבנה הקוד

| קובץ | תפקיד |
|---|---|
| `PassthroughCamera.kt` | פותח את מצלמת ה-Passthrough דרך Camera2, לפי ה-API של Meta |
| `YuvConversion.kt` | ממיר פריים מהמצלמה (YUV) לתמונה |
| `CardDetector.kt` | מריץ את מודל זיהוי הקלפים על המשקפיים (ONNX Runtime) |
| `poker/CardModel.kt` | הכנת התמונה למודל, פענוח התוצאות, הסרת כפילויות והצבעה בין 3 צילומים |
| `poker/Cards.kt` | ייצוג קלפים (0–51), קידוד כמו "Ah" ותצוגה כמו "A♥" |
| `poker/HandEvaluator.kt` | מדרג את היד הטובה ביותר מתוך 5–7 קלפים |
| `poker/EquityCalculator.kt` | סימולציית Monte Carlo לסיכויי ניצחון ו-Pot Odds, כולל טווחי יריבים |
| `poker/StartingHands.kt` / `poker/OpponentStyle.kt` | דירוג 169 ידיי הפתיחה וסוגי היריבים |
| `poker/AutoAssign.kt` | זיהוי אוטומטי: איזה קלף חדש הולך ליד שלך ואיזה לשולחן |
| `VisionViewModel.kt` | הלוגיקה: צילום, זיהוי, חישוב, שגיאות |
| `MainActivity.kt` / `PokerScreen.kt` | המסך וההרשאות (Jetpack Compose, מימין לשמאל) |
