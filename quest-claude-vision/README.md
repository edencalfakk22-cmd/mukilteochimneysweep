# Claude רואה: אפליקציה ל-Meta Quest 3S

מסתכלים על משהו, לוחצים על כפתור, והמשקפיים מצלמות את מה שמולך ושולחות ל-Claude. התשובה מוצגת בעברית ומוקראת בקול, אם יש במכשיר קול עברי.

- **"מה אני רואה?"** – תיאור קצר של מה שמולך
- **"קרא ותרגם טקסט"** – קורא שלטים, תוויות ומסמכים, ומתרגם לעברית
- **"מה זה ואיך משתמשים?"** – מזהה חפץ ומסביר איך משתמשים בו
- **שאלה חופשית** – אפשר לכתוב כל שאלה במקלדת של ה-Quest

## מה צריך

| | |
|---|---|
| משקפיים | Meta Quest 3 או 3S עם Horizon OS גרסה v74 ומעלה |
| מחשב | Windows או Mac עם [Android Studio](https://developer.android.com/studio) |
| כבל | USB-C שמעביר נתונים (הכבל שהגיע עם ה-Quest מתאים) |
| מפתח API | מ-[console.anthropic.com](https://console.anthropic.com). זה חיוב נפרד ממנוי Claude, ומשלמים לפי שימוש |

## התקנה (פעם אחת)

### 1. הפעלת מצב מפתחים ב-Quest
1. נכנסים ל-[developers.meta.com](https://developers.meta.com/horizon/) עם חשבון ה-Meta שלך ויוצרים "Organization" (בחינם). בלי זה מצב מפתחים לא נפתח.
2. באפליקציית **Meta Horizon** בטלפון: מכשירים ← בוחרים את המשקפיים ← הגדרות משקפיים ← **מצב מפתחים** ← מפעילים.
3. מפעילים מחדש את המשקפיים.

### 2. מפתח API של Claude
1. ב-[console.anthropic.com](https://console.anthropic.com) נכנסים ל-Billing וטוענים קרדיט (5$ מספיקים להרבה ניסויים).
2. ב-API Keys יוצרים מפתח חדש ומעתיקים אותו. הוא מתחיל ב-`sk-ant-`.

### 3. פתיחת הפרויקט
1. מורידים את הקוד מ-GitHub, מה-branch `claude/modest-lamport-drvsyi`.
2. ב-Android Studio בוחרים **Open** ופותחים את התיקייה `quest-claude-vision`, לא את התיקייה הראשית של ה-repo.
3. מחכים שה-Gradle Sync יסתיים. בפעם הראשונה זה יכול לקחת כמה דקות.

### 4. הוספת המפתח
פותחים את הקובץ `local.properties` בתיקייה `quest-claude-vision`. Android Studio יוצר אותו לבד. מוסיפים שורה:

```
ANTHROPIC_API_KEY=sk-ant-המפתח-שלך
```

הקובץ הזה לא עולה ל-GitHub, כי הוא ב-`.gitignore`.

### 5. הרצה על המשקפיים
1. מחברים את ה-Quest למחשב בכבל.
2. שמים את המשקפיים ומאשרים **"Allow USB debugging"**. כדאי לסמן "Always allow from this computer".
3. ב-Android Studio בוחרים את ה-Quest ברשימת המכשירים ולוחצים ▶ **Run**.
4. האפליקציה נפתחת במשקפיים. מאשרים את הרשאת המצלמה.

אחר כך אפשר למצוא את האפליקציה בספרייה של ה-Quest, תחת **Unknown Sources**.

## שימוש
1. מפעילים **Passthrough** כדי לראות את החדר (הקשה כפולה על צד המשקפיים, או מההגדרות המהירות).
2. מסתכלים על מה שרוצים לשאול עליו.
3. לוחצים על אחד הכפתורים, או כותבים שאלה ולוחצים "שאל".

התמונה שנשלחה מוצגת למטה, כך שאפשר לבדוק מה Claude ראה.

## עלות
- המודל הוא Claude Opus 5.5 (‏4$ למיליון טוקנים בקלט, 20$ למיליון בפלט).
- תמונה בגודל 1280x960 היא בערך 1,600 טוקנים.
- בסך הכול, כל שאלה עולה **בערך 1-3 סנט**.
- אפשר לעקוב אחרי ההוצאות ב-console.anthropic.com.
- רוצים זול יותר? משנים את `MODEL` בקובץ `ClaudeVision.kt` ל-`claude-haiku-5-5`, שזול בהרבה אבל פחות מדויק.

## פרטיות ואבטחה
- התמונות נשלחות ל-API של Anthropic. אל תכוון את המצלמה למסמכים רגישים, סיסמאות או אנשים שלא הסכימו.
- המפתח נבנה לתוך קובץ ה-APK. **אל תשתף את ה-APK עם אחרים**, כי אפשר לחלץ ממנו את המפתח. אם המפתח דלף, מוחקים אותו ב-console ויוצרים חדש.

## פתרון בעיות

| בעיה | פתרון |
|---|---|
| "לא נמצאה מצלמת Passthrough" | לעדכן את ה-Quest: הגדרות ← כללי ← עדכון תוכנה. צריך v74 ומעלה |
| הצבעים בתמונה הפוכים (כחול במקום אדום) | בעיה מוכרת של Meta אחרי התקנה ראשונה. מפעילים מחדש את המשקפיים |
| "לא התקבלה תמונה מהמצלמה" | לוודא שה-Passthrough פעיל ולנסות שוב |
| "מפתח ה-API לא תקין" | לבדוק את השורה ב-`local.properties` ולבנות מחדש (▶ Run) |
| "חסר מפתח API" | לא הוספת את `ANTHROPIC_API_KEY`, או שלא בנית מחדש אחרי ההוספה |
| אין הקראה בקול | כנראה שב-Quest אין קול עברי. התשובות עדיין מוצגות כטקסט |

## מבנה הקוד

| קובץ | תפקיד |
|---|---|
| `PassthroughCamera.kt` | פותח את מצלמת ה-Passthrough דרך Camera2, לפי ה-API של Meta |
| `YuvConversion.kt` | ממיר פריים מהמצלמה (YUV) ל-JPEG |
| `ClaudeVision.kt` | שולח תמונה ושאלה ל-Claude דרך ה-SDK הרשמי (`anthropic-java`) |
| `Speaker.kt` | הקראה בעברית (TextToSpeech) |
| `VisionViewModel.kt` | הלוגיקה: צילום, שליחה, שגיאות |
| `MainActivity.kt` | המסך וההרשאות (Jetpack Compose, מימין לשמאל) |
